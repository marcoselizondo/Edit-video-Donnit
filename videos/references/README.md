# 🎬 Videos de referencia

Sube aquí los videos de ejemplo que representen el **estilo que buscamos**
para los videos de Donnit (mockup de móvil, kinético, atrapante).

## Cómo subirlos

- **Opción A — GitHub:** arrastra los archivos aquí (botón *Add file → Upload files*
  en la rama `claude/ayuda-general-p9atom`) y haz commit. Luego yo hago `git pull`.
- **Opción B — Chat:** adjunta los videos directamente en la conversación
  (más rápido para archivos grandes) y yo los coloco aquí.

Formatos: `.mp4`, `.mov`.

## Qué anotar de cada referencia (opcional pero útil)

Crea un `.txt` o dímelo en el chat, con el nombre del archivo y qué te gusta:

- ⏱️ **Ritmo** — rápido/punchy o calmado/elegante
- ✨ **Animación** — mockup de móvil, kinetic type, transiciones, cámara 2.5D
- 🎨 **Estética** — paleta, mood
- 🎵 **Música/sonido** — tipo de track, cómo cuadra con la imagen
- 📌 **Momentos concretos** — "me gusta el efecto del segundo 0:05"

## Lo que buscamos (dirección actual)

- Aspecto de **mockup de móvil** (la app dentro de un teléfono realista).
- Más **cinético y atrapante** que las versiones actuales.
- **Más largo** está bien — pensado para añadirle **voz en off** después
  (dejar respiración/ritmo para la locución).
- Siempre fiel a la marca: verde `#8FD678` = donar · turquesa `#52B788` = alquiler
  · texto verde bosque `#1B4332` · fondo crema `#FAF8F5`.
